# scPoly

## Description
scPoly is a subspace-adaptive single-cell foundation model designed for heterogeneous and variable gene spaces. By learning from varying gene subsets and combining context-dependent dynamic computation with structured gene representations, scPoly adapts to the genes available in each input and supports diverse downstream tasks, including cell type annotation, cross-platform and cross-species transfer, and perturbation prediction.

## Environment Setup

This project depends on `deepspeed==0.16.5` and includes a patched `deepspeed/moe` module used by the scPoly experiments.

### Recommended setup

```bash
cd /YOURPATH/scPoly
bash env_setup/setup_env.sh
```

This script will:

- create the `scpoly` conda environment from `env_setup/environment.yml`
- install PyTorch with CUDA support through `conda`
- install the remaining Python dependencies through `pip`
- back up the original `deepspeed/moe` directory
- replace it with the patched `moe` directory bundled in this repository

### CUDA version

The default configuration uses `pytorch-cuda=12.1` in `env_setup/environment.yml`.

If your machine requires a different CUDA version, update this line before running the setup script:

```yaml
pytorch-cuda=12.1
```

### Manual setup

If needed, the same setup can also be run manually with `env_setup/environment.yml`, `env_setup/requirements-scpoly-pip.txt`, and `env_setup/install_patched_moe.sh`.

### Hardware recommendation

The provided example commands are configured for a single machine with 6 GPUs. We recommend using at least 3 GPUs for running the project.


## Download Data and Checkpoints

Pretrained checkpoint and most of the processed datasets used in scPoly are available at: [Download](https://doi.org/10.6084/m9.figshare.32621973). For specific datasets used for each task, please refer to the [Supported Tasks](#supported-tasks) section.


Please download the required files from this link before running experiments.

Please keep the original folder structure after downloading and extracting the files.

Recommended local directory layout:

- place checkpoints (model.safetensors) under `ckpt_scPoly/`
- place processed datasets under `data/`


The project also uses additional files such as gene order files and the extended vocabulary. These are already organized under `meta_info/`. The extended vocabulary will also be provided inside the corresponding dataset folders when applicable.

Each task folder follows the same pattern:

- `trainer.py`: fine-tuning (task training)
- `infer.py`: inference (downstream prediction)
- `save/`: generated at runtime and used for trained checkpoints and outputs


## Run Tasks

Each task is organized as a separate folder under `tasks/`. In each task folder:

- `trainer.py` is used for training
- `infer.py` is used for inference

The example running commands are provided at the end of each `trainer.py` and `infer.py` file.

The `annotation` example below is only a demonstration. Other tasks under `tasks/` can be run in the same way.

### Demo: annotation

```bash
cd /YOURPATH/scPoly/tasks/annotation
nohup deepspeed --include localhost:0,1,2,3,4,5 --master_port 29611 trainer.py --dataset pancreas16k > trainer.log 2>&1 &
nohup deepspeed --include localhost:0,1,2,3,4,5 --master_port 29611 infer.py --dataset pancreas16k --exp-id 2026-06-17-17-52 > infer.log 2>&1 &
```

`29611` is an example communication port for DeepSpeed. If this port is already in use on your machine, please change it to another available port.

`2026-06-17-17-52` is the experiment ID generated by the training run, typically based on the training timestamp. When running inference, replace it with the actual experiment ID produced by your own training job.
